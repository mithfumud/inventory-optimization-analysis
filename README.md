# Inventory Optimization & Performance Analysis

An end-to-end data analytics portfolio project using **Python**, **Excel**, **SQL**, and **Power BI** to analyze inventory performance and identify optimization opportunities.

> Status: Project setup. Data and analysis coming soon.

## Project Structure

```
inventory-optimization-analysis/
├── data/
│   ├── raw/            # Original, untouched source data
│   └── cleaned/        # Processed data ready for analysis
├── scripts/            # Python scripts for cleaning and analysis
├── sql/                # SQL queries for data exploration and KPIs
├── powerbi/            # Power BI dashboard files (.pbix) and screenshots
├── documentation/      # Data dictionary, methodology, and findings
└── README.md           # Project overview (this file)
```

## Tools

| Tool     | Purpose                                  |
|----------|------------------------------------------|
| Python   | Data cleaning, transformation, analysis  |
| Excel    | Initial data inspection and quick checks |
| SQL      | Querying and KPI calculations            |
| Power BI | Interactive dashboards and reporting     |
